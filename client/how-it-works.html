How the voice arcade works

A phone call moves the game.

Call from your phone and say your move. Twilio carries the conversation, the game checks the action, and the shared screen updates. You hear the result on the same call.

Jump into the conversation

Speak over a greeting or menu; your choice can start before the voice finishes.

Use your own words

Speak in your own accent or phrasing. The game uses the current screen to interpret your request and asks when it is unsure.

Tap a visible menu

Anyone by the screen can tap a menu, while the caller controls live moves and answers by voice.

For builders

From call to shared screen

Twilio handles speech; the game server validates actions. What players hear and see comes from the same validated state.

01

Connect the call

Twilio sends a signed webhook. The server validates it, selects the game room, and returns TwiML to connect the call to Conversation Relay.

02

Validate the move

Direct commands take a fast path. For flexible speech, optional AI selects from actions allowed on the current screen; the game validates the result.

03

Update both sides

The server sends validated room state over WebSocket to the browser and a matching spoken reply through Conversation Relay.

01 / TwiML

Connect the caller

The webhook returns TwiML that opens Conversation Relay and lets callers interrupt greetings and replies.

<Connect
  action="https://example.com/voice/session-ended">
  <ConversationRelay
    url="wss://example.com/voice"
    transcriptionProvider="Deepgram"
    speechModel="flux"
    ttsProvider="ElevenLabs"
    voice="SA7eD52NRr8WAehitVt1-flash_v2"
    partialPrompts="true"
    interruptible="any"
    welcomeGreetingInterruptible="any"
    reportInputDuringAgentSpeech="any">
    <Parameter name="roomCode" value="ABCD" />
  </ConversationRelay>
</Connect>

Karaoke briefly switches to live audio.

During a song, the call carries live audio for timing and pitch, then returns to the voice guide for the score.

How the audio handoff works

Conversation Relay guides song choice and asks for explicit consent. During the song, an authenticated inbound Twilio Media Stream carries only the caller’s audio. The server measures timing and pitch while Deepgram recognizes lyrics. Conversation Relay returns to announce the score.
