How the voice arcade works

A phone call moves the game.

Your phone is the controller. Twilio Conversation Relay listens and speaks, while the game server decides what your words mean right now. Everyone sees the move on one shared screen.

Under the hood

What connects the call to the screen?

The live path has three handoffs. Twilio handles the call. The server owns the rules. The browser draws the current room.

01

Connect the call

When a call arrives, Twilio sends a signed request (a webhook). The server identifies the game room and returns TwiML, Twilio’s call instructions, to connect Conversation Relay.

POST /voice/incoming
<ConversationRelay>
02

Understand the turn

Quick commands take a fast path. For less direct speech, an optional AI interpreter chooses only from actions and facts available on the current screen. The game validates the choice before changing state.

WebSocket /voice
current phase → allowed action
03

Render the result

A live browser connection (WebSocket) carries the room state. The browser draws the race, board, battle, stage, or score. When the voice guide is active, it describes the same result.

/game · /battle · /fighter
/karaoke · /trivia · /chess

01 / TwiML

Connect the caller

The incoming-call webhook returns instructions that open Conversation Relay. These settings let players cut into greetings and replies.

<Connect
  action="https://example.com/voice/session-ended">
  <ConversationRelay
    url="wss://example.com/voice"
    transcriptionProvider="Deepgram"
    speechModel="flux"
    ttsProvider="ElevenLabs"
    voice="SA7eD52NRr8WAehitVt1-flash_v2"
    partialPrompts="true"
    interruptible="any"
    welcomeGreetingInterruptible="any"
    reportInputDuringAgentSpeech="any">
    <Parameter name="roomCode" value="ABCD" />

</Connect>

02 / WebSocket

Speak the response

Relay sends the caller’s transcript as a prompt. After the game checks the action, the server sends reply text for Twilio to speak.

ws.send(JSON.stringify({
  type: 'text',
  token: wireTokens[index],
  last: index === wireTokens.length - 1,
  lang: locale,
  interruptible: true,
  preemptible: true,
}));

Made for people

You can talk like a player.

The call is a conversation, not a list of magic phrases. The game still checks every action against its rules.

↯

Cut in whenever you’re ready

Speak over a welcome, menu, or explanation. Conversation Relay reports your speech while the voice is still talking, so the next choice can start right away.

≈

Say it your way

Players can speak in their own accent or wording. Twilio transcribes the call; game-word hints help with names, and the current screen helps resolve likely misheard words. Ambiguous requests get a short follow-up.

◎

Tap menus on the shared screen

Anyone nearby can tap a visible menu or selector. Live moves, attacks, answers, and racing commands stay with the phone player.

A special performance lane

Karaoke switches from talking to singing.

Conversation Relay guides song choice and asks for explicit consent. During the song, an authenticated inbound Twilio Media Stream carries only the caller’s audio. The server measures timing and pitch, while Deepgram recognizes lyrics. Conversation Relay returns to announce the score.

Relay→Media Stream→Score→Relay
